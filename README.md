# Шлёпа (Shlepa) 🐾

Веселое Android-приложение для измерения силы ваших шлепков с помощью акселерометра. Просто имитируйте шлепок телефоном в руке, и приложение оценит вашу мощь!

## 🚀 Основные возможности

*   **Измерение силы:** Использует данные акселерометра для вычисления интенсивности удара в реальном времени.
*   **Интерактивный отклик:** Динамические звуки шлепков и вибрация, которые зависят от того, насколько сильным был «удар».
*   **Рекорды и статистика:** 
    *   Счетчик общего количества шлепков.
    *   Сохранение вашего личного рекорда силы.
    *   История последних 5 ударов для сравнения.
*   **Гибкая настройка:** Слайдер порога чувствительности позволяет настроить приложение под любой смартфон и стиль шлепков.
*   **Современный дизайн:** Полностью написано на **Jetpack Compose** с использованием **Material 3** и плавной анимацией.

## 🛠 Технологии

*   **Язык:** Kotlin
*   **UI:** Jetpack Compose (Material 3)
*   **Архитектура:** MVVM (ViewModel, State)
*   **Датчики:** SensorManager (Accelerometer)
*   **Мультимедиа:** SoundPool (минимальные задержки звука) и VibrationManager

## 📱 Как пользоваться

1. Запустите приложение.
2. Отрегулируйте порог чувствительности (если датчик слишком чуткий или наоборот).
3. Совершите резкое движение телефоном (имитация шлепка).
4. Услышьте заветный **ШЛЁП!** и проверьте свою силу на экране.
